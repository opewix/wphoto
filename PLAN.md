# WPhoto — просмотр рисунков в духе Windows для macOS

Цель: просмотрщик, похожий на «Средство просмотра фотографий Windows» (Vista / 7) и «Программу
просмотра изображений и факсов» (XP) по виду и поведению: открыл рисунок — листаешь папку стрелками.
Главное — скорость.

## Решения

- **Стек:** Swift + AppKit, SwiftPM без Xcode, как у WExplorer и WTaskbar. `scripts/bundle.sh`
  собирает `build/WPhoto.app`, `scripts/make-dmg.sh` — образ.
- **Скорость:** ImageIO декодирует в фоне сразу под размер экрана (`Model/ImageLoader.swift`), соседи
  (+1, −1, +2) — заранее, готовое — в `NSCache` (до 1,2 ГБ). Пока большой файл декодируется,
  показывается встроенная миниатюра. Полное разрешение — только при увеличении. Устаревшие запросы
  при удержании стрелки пропускаются.
- **Отрисовка:** рисунок — `CALayer` с готовой картинкой; масштаб, сдвиг и поворот — геометрия слоя,
  без перерисовки. Масштаб 1 = пиксель рисунка на пиксель экрана; «по размеру окна» не растягивает
  маленькие рисунки, как в Windows.
- **Поворот пишет в файл**, как в Windows, но без потерь: `CGImageDestinationCopyImageSource` меняет
  только ориентацию EXIF. Пишем во временный файл, проверяем формат, размер и ориентацию, потом
  подменяем. Не вышло (GIF, многокадровый HEIC) — поворот только на экране.
- **Список** — рисунки папки по имени (`localizedStandardCompare`, как Finder) либо файлы, открытые
  вместе. Папка отслеживается (`DispatchSource`), состав обновляется сам.
- **Окно одно:** двойной щелчок в Finder открывает рисунок в уже открытом окне. Новое — ⌘N.
- **Клавиши:** стрелки, Delete, +/−, пробел обрабатывает окно (повторяются при удержании без
  мигания меню), команды с ⌘ — в меню. Сочетания Windows Ctrl+. / Ctrl+, тоже работают.
- **Темы** (`Theme/Theme.swift`, `Views/Bars.swift`): Vista / 7 — панель «Файл / Печать /
  Поделиться / Открыть» сверху и голубая панель с шаром слайд-шоу снизу; XP — белое окно и строка
  мелких кнопок группами.
- **Графика своя** (`Theme/Glyphs.swift`): значки и иконка программы рисуются кодом.
- **Проверка вида:** `WPhoto -snapshot <папка> [-theme xp] <рисунок>` — окно в PNG.
